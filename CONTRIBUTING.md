# Contribuindo

1. Abra uma issue descrevendo motivação e escopo.
2. Crie uma branch curta e mantenha o PR focado.
3. Instale com `make install` e execute `make check`.
4. Atualize testes e documentação quando mudar comportamento.
5. Use mensagens de commit claras; não inclua segredos nem dados reais.

O projeto segue revisão por pull request. Ao contribuir, você concorda que sua contribuição seja licenciada sob MIT.
