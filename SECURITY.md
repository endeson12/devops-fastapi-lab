# Política de segurança

## Versões suportadas

Enquanto este projeto-vitrine estiver mantido, apenas a versão mais recente da branch `main` recebe correções. Ele é demonstrativo e não representa um serviço em produção.

## Relato responsável

Não abra uma issue pública com detalhes exploráveis. Use **Security > Report a vulnerability** no GitHub (Private Vulnerability Reporting). Inclua impacto, reprodução e sugestão de mitigação. Não há SLA garantido; o mantenedor acusará recebimento e coordenará a divulgação conforme disponibilidade.

Nunca inclua credenciais, dados pessoais ou tokens no relato.
